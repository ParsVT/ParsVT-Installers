# نصب‌کنندهٔ ویندوزی ParsVT CRM

نصب‌کنندهٔ خودکار **ParsVT CRM** (نسخهٔ فارسی Vtiger CRM) برای Windows Server.
همهٔ اجزای لازم را نصب و تنظیم می‌کند: Apache، PHP، MariaDB، ionCube، CRM، پشتیبان‌گیری روزانه، Cron و در صورت نیاز phpMyAdmin و گواهی SSL.
روی PowerShell خود ویندوز اجرا می‌شود و به XAMPP یا Cygwin نیازی ندارد.

نسخهٔ فعلی: **2.11**

## پیش‌نیازها

| مورد | مقدار |
|---|---|
| سیستم‌عامل | Windows Server 2016، 2019 یا 2022 (64 بیتی) |
| دسترسی | حساب Administrator |
| فضای دیسک | حداقل 2 گیگابایت؛ 10 گیگابایت یا بیشتر برای پشتیبان‌ها پیشنهاد می‌شود |
| اینترنت | دسترسی HTTPS به `aweb.co` و `license.aweb.co` (همهٔ فایل‌ها از آنجا دانلود می‌شوند) |
| لایسنس | کلید لایسنس معتبر ParsVT (با `ParsVT` یا `Cloud` شروع می‌شود) |
| پورت | پورت 80 آزاد باشد (یا هنگام نصب پیشرفته پورت دیگری انتخاب کنید)؛ برای SSL پورت 443 |

روی این سرورها **نصب نکنید**:

- سرورهایی که کنترل پنل دارند (Plesk و مانند آن). نصب‌کننده خودش متوقف می‌شود.
- سرورهایی که IIS یا XAMPP روی پورت 80 دارند، مگر اینکه پورت دیگری انتخاب کنید.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `Install ParsVT.cmd` | لانچر یک‌کلیکی برای کاربر عادی |
| `parsvt.ps1` | نصب‌کنندهٔ اصلی |
| `preflight.ps1` | بررسی سرور پیش از نصب؛ هیچ تغییری روی سرور نمی‌دهد |

هر سه فایل باید **در یک پوشه** باشند. اگر آن‌ها را به‌صورت ZIP دانلود کرده‌اید، اول کل ZIP را در یک پوشهٔ محلی مثل `C:\ParsVT-Setup` استخراج کنید و فایل را از داخل ZIP اجرا نکنید.

## نصب سریع (پیشنهادی)

برای کاربری که اطلاعات فنی ندارد:

1. سه فایل را در `C:\ParsVT-Setup` قرار دهید.
2. روی `Install ParsVT.cmd` دابل‌کلیک کنید و پنجرهٔ UAC (دسترسی Administrator) را تأیید کنید.
3. نسخه را انتخاب کنید:
   - `1` یا فقط Enter: Vtiger 8 / PHP 8.3 (پیشنهادی)
   - `2`: Vtiger 7 / PHP 7.4 (منسوخ؛ فقط برای سازگاری با نصب‌های قدیمی). یک تأیید دوم (`y`) لازم دارد، چون PHP 7.4 از نوامبر 2022 وصلهٔ امنیتی ندارد.
   - `0`: انصراف
4. **کلید لایسنس** را وارد کنید و منتظر بمانید (حدود 10 تا 20 دقیقه، بسته به سرعت اینترنت).
5. در پایان آدرس CRM، نام کاربری و رمز عبور نمایش داده می‌شوند. همین اطلاعات در `C:\parsvt-credentials.txt` هم ذخیره می‌شوند.

به‌جز نسخه و کلید لایسنس، نصب سریع این مقادیر پیش‌فرض را بدون پرسش استفاده می‌کند:

| تنظیم | مقدار |
|---|---|
| پورت | 80 |
| مسیر Apache | `C:\Apache24` |
| مسیر CRM | `C:\Apache24\htdocs` |
| دامنه و SSL | ندارد (بخش [دامنه و SSL](#دامنه-و-ssl) را ببینید) |
| phpMyAdmin | نصب می‌شود و فقط از خود سرور و شبکهٔ داخلی در دسترس است |
| Windows Defender | پوشه‌های برنامه، پشتیبان و دیتابیس از اسکن معاف می‌شوند (پوشهٔ CRM معاف نمی‌شود) |

نکته‌ها:

- پیش از نصب، `preflight.ps1` خودکار اجرا می‌شود. اگر مشکلی پیدا کند، نصب شروع نمی‌شود و چیزی روی سرور تغییر نمی‌کند.
- اگر CRM از قبل روی سرور نصب باشد، نصب سریع به‌جای نصب دوباره **تعمیر (Repair)** انجام می‌دهد و داده‌ها حفظ می‌شوند.
- اگر نصب با خطا مواجه شود، یک پیام فارسی نمایش داده می‌شود و فایل `ParsVT-Report-<تاریخ>.zip` روی دسکتاپ ساخته می‌شود. آن را برای پشتیبانی بفرستید (بخش [عیب‌یابی](#عیب‌یابی) را ببینید).

## نصب پیشرفته (با منو)

برای انتخاب پورت، مسیرها، دامنه و SSL:

1. PowerShell را با **Run as administrator** باز کنید.
2. پیشنهاد می‌شود اول پیش‌بررسی را اجرا کنید:

   ```powershell
   cd C:\ParsVT-Setup
   powershell -NoProfile -ExecutionPolicy Bypass -File .\preflight.ps1
   ```

   هر مورد `FAIL` را قبل از نصب رفع کنید. موارد `WARN` را بخوانید.

3. نصب‌کننده را اجرا کنید:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\parsvt.ps1
   ```

4. از منو یک گزینه را انتخاب کنید:

   | گزینه | کار |
   |---|---|
   | `1` | نصب ParsVT CRM با Vtiger 8 / PHP 8.3 (پیشنهادی) |
   | `2` | نصب ParsVT CRM با Vtiger 7 / PHP 7.4 (منسوخ؛ فقط برای سازگاری با نصب‌های قدیمی) |
   | `3` | تعمیر نصب موجود |
   | `4` | فقط به‌روزرسانی ionCube |
   | `0` | انصراف |

پرسش‌های نصب به ترتیب:

1. کلید لایسنس
2. IP سرور (اگر سرور چند IP داشته باشد). این IP آدرس CRM و آدرسی است که Cron صدا می‌زند.
3. نام دامنه (اختیاری؛ خالی بگذارید تا بدون دامنه نصب شود)
4. مسیر Apache و مسیر CRM (web root)
5. پورت وب‌سرور
6. معاف کردن پوشه‌ها از Windows Defender (پیشنهاد: `y`)
7. محدود کردن phpMyAdmin به شبکهٔ داخلی (پیشنهاد: `y`)
8. در پایان: نصب گواهی SSL (اگر دامنه وارد نکرده باشید، همان‌جا پرسیده می‌شود)

اگر روی مسیری که انتخاب کرده‌اید CRM یا دیتابیسی از قبل وجود داشته باشد، نصب‌کننده تا کلمهٔ `OVERWRITE` را تایپ نکنید ادامه نمی‌دهد. پوشهٔ قبلی پاک نمی‌شود و با نام `htdocs.old-<تاریخ>` کنار گذاشته می‌شود. از دیتابیس قبلی هم پیش از جایگزینی در `C:\backup` نسخهٔ پشتیبان گرفته می‌شود.

## بعد از نصب

### اطلاعات ورود

همهٔ اطلاعات در `C:\parsvt-credentials.txt` ذخیره شده است: آدرس CRM، نام کاربری و رمز `admin`، رمز MariaDB و مسیرها. این فایل فقط برای Administratorها قابل خواندن است. **پس از برداشتن اطلاعات، آن را به جای امنی منتقل کنید.**

### آدرس‌ها

| سرویس | آدرس |
|---|---|
| CRM | `http://<IP-سرور>/` (روی پورت غیر 80: `http://<IP-سرور>:<پورت>/`) |
| phpMyAdmin | `http://<IP-سرور>/phpmyadmin/` |
| REST API | `http://<IP-سرور>/modules/ParsVT/ws/api/...` |

### مسیرها

| مورد | مسیر |
|---|---|
| Apache | `C:\Apache24` (سرویس `Apache2.4`) |
| فایل‌های CRM | `C:\Apache24\htdocs` |
| PHP | `C:\PHP\8.3` (یا `C:\PHP\7.4`) |
| MariaDB | `C:\Program Files\MariaDB 10.11` (سرویس `MariaDB`) |
| پشتیبان‌ها | `C:\backup` |
| اسکریپت‌های پشتیبان و بازگردانی | `C:\Program Files\ParsVT` |
| لاگ‌ها | `C:\parsvt-logs` و `C:\Apache24\logs` |

### میانبرها

روی دسکتاپ همهٔ کاربران و در منوی Start دو میانبر ساخته می‌شود:

- **Restart ParsVT Webserver**: پیکربندی Apache را بررسی می‌کند و فقط اگر سالم باشد Apache را دوباره راه‌اندازی می‌کند.
- **Restart ParsVT Database**: سرویس MariaDB را دوباره راه‌اندازی می‌کند.

### کارهای زمان‌بندی‌شده

| نام | زمان | کار |
|---|---|---|
| `ParsVT-Backup` | هر روز ساعت 22:00 | پشتیبان دیتابیس و فایل‌ها |
| `ParsVT-VtigerCron` | هر 15 دقیقه | اجرای `vtigercron.php` (ایمیل‌ها، یادآورها، گردش‌کارها) |

Cron روی Server 2019 و 2022 با `curl.exe` آدرس `http://<IP-سرور>/vtigercron.php` را صدا می‌زند. Server 2016 `curl.exe` ندارد، پس آنجا با `php.exe` اجرا می‌شود.
**اگر IP سرور عوض شد، گزینهٔ تعمیر (`3`) را اجرا کنید** تا Cron به IP جدید تنظیم شود.

## تعمیر و به‌روزرسانی

گزینهٔ `3` (Repair) این کارها را انجام می‌دهد، **بدون اینکه به داده‌ها و فایل‌های CRM دست بزند**:

- تنظیمات Apache و PHP و ionCube را از نو می‌نویسد.
- کارهای زمان‌بندی‌شده، میانبرها، اسکریپت‌های پشتیبان، فایروال و PATH را بازسازی می‌کند.
- مسیرهای اشتباه صفحه‌های خطا را در `.htaccess` ریشه اصلاح می‌کند و نسخهٔ اصلی را با پسوند `.parsvt-bak-<تاریخ>` نگه می‌دارد.
- در پایان، آدرس REST API و صفحهٔ خطا را بررسی می‌کند.

چه زمانی تعمیر را اجرا کنید:

- بعد از دانلود نسخهٔ جدید نصب‌کننده
- بعد از تغییر IP سرور
- وقتی Apache یا PHP درست کار نمی‌کند

برای به‌روزرسانی فقط ionCube از گزینهٔ `4` استفاده کنید. Apache چند ثانیه متوقف می‌شود.

## پشتیبان‌گیری و بازگردانی

پشتیبان‌گیری هر شب ساعت 22:00 خودکار انجام می‌شود و فایل‌ها در `C:\backup` ذخیره می‌شوند:

- `parsvt-db-<تاریخ>.sql.gz`: دیتابیس، همراه با توابع، triggerها و eventها
- `parsvt-files-<تاریخ>.zip`: فایل‌های CRM، بدون پوشه‌های `cache` و `tmp`

پشتیبان‌های قدیمی‌تر از 7 روز خودکار حذف می‌شوند. **نسخه‌ای از پشتیبان‌ها را روی سرور یا دیسک دیگری هم نگه دارید.**

### پشتیبان‌گیری دستی

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Program Files\ParsVT\backup.ps1"
```

### بازگردانی

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Program Files\ParsVT\restore.ps1"
```

1. فهرست پشتیبان‌ها نمایش داده می‌شود. شمارهٔ پشتیبان موردنظر را وارد کنید.
2. برای تأیید، نام دیتابیس (`parsvt`) را تایپ کنید.
3. پیش از بازگردانی، از وضعیت فعلی یک نسخهٔ ایمنی گرفته می‌شود، با نام `parsvt-db-prerestore-<تاریخ>.sql`.

لاگ‌ها در `C:\parsvt-logs\crm_backup.log` و `C:\parsvt-logs\crm_restore.log` ذخیره می‌شوند.

## دامنه و SSL

پیش‌نیازها:

- رکورد DNS دامنه به IP عمومی سرور اشاره کند.
- پورت 80 از اینترنت به سرور باز باشد. Let's Encrypt دامنه را از این پورت بررسی می‌کند، حتی اگر CRM روی پورت دیگری باشد.
- پورت 443 آزاد باشد.

مراحل:

1. هنگام نصب پیشرفته (بدون `-Quick`) دامنه را وارد کنید.
2. در پایان به پرسش `Install SSL certificate now?` جواب `y` بدهید و یک ایمیل برای اطلاع‌رسانی‌های Let's Encrypt وارد کنید.
3. گواهی با win-acme دریافت می‌شود و خودکار تمدید می‌شود.
4. پس از فعال شدن SSL، مقدار `$site_URL` را در `C:\Apache24\htdocs\config.inc.php` به `https://<دامنه>/` تغییر دهید.

> در نسخهٔ فعلی، SSL فقط در پایان نصب جدید فعال می‌شود. منو گزینه‌ای برای افزودن دامنه و SSL به CRM نصب‌شده ندارد. گزینهٔ `1` روی سرور نصب‌شده، CRM را از نو نصب می‌کند.

## phpMyAdmin

- آدرس: `http://<IP-سرور>/phpmyadmin/`
- ورود: کاربر `root` و رمز MariaDB از `C:\parsvt-credentials.txt`. ورود با رمز خالی پذیرفته نمی‌شود.
- به‌صورت پیش‌فرض فقط از خود سرور و شبکه‌های داخلی (`10.x`، `172.16-31.x`، `192.168.x`) در دسترس است.
- خارج از پوشهٔ CRM نصب می‌شود (`C:\Apache24\phpmyadmin`) و هیچ رمزی در فایل تنظیماتش ذخیره نمی‌شود.

## REST API و وب‌سرویس‌ها

آدرس‌های کوتاه از طریق `.htaccess` به اسکریپت مربوط هدایت می‌شوند. نصب‌کننده PHP را طوری تنظیم می‌کند که این آدرس‌ها درست کار کنند.

| سرویس | آدرس کوتاه | آدرس مستقیم |
|---|---|---|
| REST API V2 | `/modules/ParsVT/ws/api/V2/...` | `/modules/ParsVT/ws/Api.php/V2/...` |
| پورتال مشتریان | `/modules/ParsVT/ws/portal/...` | `/modules/ParsVT/ws/Portal.php/...` |
| SOAP | `/modules/ParsVT/ws/soap/...` | `/modules/ParsVT/ws/soap.php/...` |
| MCP | `/mcp` | `/modules/ParsVT/ws/mcp.php` |

آزمایش (روی Server 2019 و 2022):

```powershell
curl.exe -i -u admin:<ACCESS_KEY> http://127.0.0.1/modules/ParsVT/ws/api/V2/vtiger/default/ping
```

`ACCESS_KEY` را از صفحهٔ My Preferences کاربر بردارید. پاسخ باید JSON باشد، نه `No input file specified`.

## عیب‌یابی

### گزارش خطا

اگر نصب با خطا تمام شود، فایل `ParsVT-Report-<تاریخ>.zip` روی دسکتاپ ساخته می‌شود. این فایل شامل لاگ‌های نصب، Apache، PHP و MariaDB، فایل‌های تنظیمات و اطلاعات سیستم است.
رمزها از لاگ‌ها حذف می‌شوند و `C:\parsvt-credentials.txt`، `config.inc.php` و `backup.cnf` هرگز داخل گزارش قرار نمی‌گیرند. این فایل را برای پشتیبانی ParsVT بفرستید.

### لاگ‌ها

| لاگ | مسیر |
|---|---|
| نصب | `C:\parsvt-logs\install-<تاریخ>.log` |
| خطاهای PHP | `C:\parsvt-logs\php-8.3-error.log` |
| Apache | `C:\Apache24\logs\error.log` |
| پشتیبان و بازگردانی | `C:\parsvt-logs\crm_backup.log`، `crm_restore.log` |

### مشکلات رایج

| نشانه | راه‌حل |
|---|---|
| `running scripts is disabled on this system` | از `Install ParsVT.cmd` استفاده کنید، یا PowerShell را با `-ExecutionPolicy Bypass` اجرا کنید (مانند دستورهای بالا) |
| `Invalid license key format` | کلید را دوباره و با دقت کپی کنید. پیام خطا علت را می‌گوید (طول کلید یا پیشوند آن) |
| Apache اجرا نمی‌شود و خطای `VCRUNTIME140` می‌دهد | Visual C++ Redistributable قدیمی است. تعمیر (`3`) را اجرا کنید |
| `could not bind` یا پورت 80 اشغال است | برنامهٔ دیگری (IIS، Skype، XAMPP) پورت را گرفته. آن را متوقف کنید یا در نصب پیشرفته پورت دیگری انتخاب کنید |
| REST API پیام `No input file specified` می‌دهد | تعمیر (`3`) را با نسخهٔ 2.11 یا جدیدتر اجرا کنید |
| به‌جای صفحهٔ خطا متن `/modules/ParsVT/errors/` نمایش داده می‌شود | تعمیر (`3`) را اجرا کنید |
| Cron اجرا نمی‌شود | `Get-ScheduledTaskInfo ParsVT-VtigerCron` را بررسی کنید. اگر IP سرور عوض شده، تعمیر (`3`) را اجرا کنید |
| `php` یا `mysql` در خط فرمان پیدا نمی‌شود | یک پنجرهٔ CMD **جدید** از منوی Start باز کنید |

---

## نکات امنیتی

- رمز `admin` را پس از اولین ورود عوض کنید و `C:\parsvt-credentials.txt` را از سرور خارج کنید.
- phpMyAdmin را به اینترنت باز نکنید. اگر در نصب پیشرفته محدودیت را برداشته‌اید، آن را با تعمیر دوباره فعال کنید.
- پشتیبان‌ها را روی سرور دیگری هم نگه دارید. پشتیبانی که فقط روی همان سرور باشد، در صورت خرابی دیسک یا باج‌افزار از بین می‌رود.
- اگر CRM از اینترنت در دسترس است، دامنه و SSL را فعال کنید.

## پارامترهای خط فرمان

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\parsvt.ps1 [-Quick] [-Vtiger 8|7] [-SkipPreflight] [-DryRun]
```

| پارامتر | کار |
|---|---|
| (بدون پارامتر) | نصب پیشرفته با منو |
| `-Quick` | نصب سریع؛ فقط نسخهٔ Vtiger و کلید لایسنس پرسیده می‌شوند. همان کاری است که `Install ParsVT.cmd` انجام می‌دهد |
| `-Vtiger 8` / `-Vtiger 7` | همراه `-Quick`: همان نسخه بدون پرسش نصب می‌شود (برای نصب خودکار) |
| `-SkipPreflight` | همراه `-Quick`: پیش‌بررسی را اجرا نمی‌کند |
| `-DryRun` | اجرای آزمایشی؛ مراحل را نمایش می‌دهد ولی هیچ تغییری روی سرور نمی‌دهد |
